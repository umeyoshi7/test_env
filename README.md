# 戦艦ゲーム (Battleship)

スマートフォン向けの戦艦ゲームです。ブラウザだけで動く静的サイトとして実装されています (HTML/CSS/JS のみ、依存ゼロ・ビルド不要)。

## 遊び方

1. **配置フェーズ**: 自陣の 8×8 ボードに 5 隻 (戦艦・巡洋艦・駆逐艦・潜水艦・哨戒艇) を配置します。
   - 艦リストから艦を選び、ボードのセルをタップして配置
   - 「向き切替」で縦横を切り替え
   - 「ランダム配置」で全艦を自動配置
   - 「リセット」で配置をやり直し
2. **戦闘フェーズ**: 「開始」を押すと敵 (CPU) のボードが生成されます。敵陣のセルをタップして攻撃。
   - 命中・ミス・撃沈が表示されます
   - プレイヤーと CPU が交互に攻撃
3. **勝利条件**: 相手の全艦を先に撃沈すれば勝利

## 実行方法

### ローカルブラウザで遊ぶ

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くだけ。

(`index.html` をダブルクリックして直接開いても動きます)

### スマホで遊ぶ

同じ Wi-Fi に接続したスマホから、PC の IP アドレス (例: `http://192.168.1.10:8000`) にアクセスしてください。

GitHub Pages にもそのままデプロイ可能です。

## 技術構成

- Vanilla HTML / CSS / JavaScript のみ
- フレームワーク・ビルドツール・依存ライブラリ無し
- スマホ縦画面に最適化 (タッチ操作、レスポンシブ)
- CPU AI は **ハントモード搭載** (命中後は隣接セルを優先攻撃)

## ファイル構成

- `index.html` — マークアップとフェーズ切替の DOM 構造
- `style.css`  — モバイルファーストのスタイル、グリッドレイアウト
- `game.js`   — ゲーム状態・配置・戦闘・AI ロジック
